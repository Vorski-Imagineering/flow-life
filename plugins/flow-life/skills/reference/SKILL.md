# reference: keep what was learned, with its source

Read `${CLAUDE_PLUGIN_ROOT}/references/rules.md` (Reference, Sensitive data) first.

1. **Where**: the area's `reference.md`; `shared/reference.md` if it serves several areas.
   Look for an existing entry on the same subject and update it rather than add a second.
2. **Entry**: a heading naming the subject, then source link or local path, date checked,
   short summary, key quotes (in the original language, with a translation if useful), and
   the practical implication for the open processes.
3. **Sources**: official ones first (government, the body itself, the law). Mark anything
   from a forum or a person as such.
4. **Local providers**: name, address, phone/email, website.
5. **No identifiers**, ever: write "the residence request", not its number. The repo check
   fails otherwise.
6. If it changes what a process should do next, update that process's todo and `Next`.
